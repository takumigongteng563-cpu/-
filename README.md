# 山羊の野望

ブラウザで遊ぶ国取りゲーム。ひとりでAIと遊ぶことも、友だちと2〜4人で遊ぶこともできる。設計は [SPEC.md](SPEC.md)。

## 動かし方（Windows・いちばんかんたん）

1. https://nodejs.org を開いて、緑の大きなボタンから Node.js をダウンロードして入れる（「次へ」を押していけばOK）
2. このページの緑の「Code」ボタン →「Download ZIP」でダウンロードして、右クリック →「すべて展開」
3. 展開したフォルダの中の **start.bat** をダブルクリック
4. ブラウザが開いてゲームが始まる（開かなければ http://localhost:3000 を開く）

やめるときは、黒い画面を閉じる。

## インターネットで友だちと遊ぶ（Windows）

1. 上の 1・2 と同じ準備をする
2. **online.bat** をダブルクリック（はじめの1回だけ、つなぐための道具を自動でダウンロードする）
3. ロビーに「友だちに送るURL」が出るので、コピーして友だちに送る
4. 友だちはそのURLをブラウザで開いて、空いている役を選んで参加する

- このパソコンでゲームを動かしているあいだだけ遊べる。セーブはこのパソコンに残る
- URLは起動するたびに変わる。友だちが自分の役に戻るときは、ロビーで自分の役のボタン（🔑）を押して「あいことば」（ゲーム画面の右上に出る4けたの数字）を入れる
- つなぐ道具は Cloudflare のもの（アカウント登録はいらない）。URLを知っている人はだれでもロビーに入れるので、URLは遊ぶ友だちにだけ送る

## 動かし方（くわしく）

Node.js 20 以上が必要（追加のインストールはなし）。

```
npm start
```

ブラウザで http://localhost:3000 を開く。

- **ひとりで遊ぶ**：ロビーの「王国で遊ぶ」か「魔族で遊ぶ」を押すだけ。相手はAI（むずかしさを選べる）
- **友だちと遊ぶ**：「友だちと遊ぶ」でゲームを作り、役（ヤギュー・スミレ・野口・七星）を選んで参加して「ゲームを始める」。空いている役はAIが動かす
- 遊び方は、ロビーやゲーム中の「遊び方」ボタンで見られる

友だちと遊ぶときは、サーバーを動かしているPCのアドレス（例：`http://192.168.0.10:3000`）を開いてもらう。

ゲームは `data/` フォルダに自動で保存される。サーバーを止めても、次に起動すればロビーの「続きから」で再開できる。

## テスト

```
npm test                          # ヤギューとスミレだけ（150日ぶん自動で進める）
node test/sim.js 150 all          # 4人ぶんを自動で進める
node test/sim.js 80 all trial     # お試しモード（全員Lv30）で進める
node test/each-skill.js           # すべての技を1回ずつ使ってみる
node test/skills.js 20            # Lv30どうしの大合戦で、AIが技を使うか見る
node test/balance.js 15 0         # 合戦の組み合わせごとの王国の勝率（Lv15・訓練0）
node test/aivsai.js 10 200        # 王国AI vs 魔族AI で最後まで流す
node test/royale.js 10            # バトルロワイヤルをAIだけで流す
```

ロビーで「お試しモード」にチェックを入れてゲームを作ると、全員Lv30から始まるので技をすぐ試せます。

## フォルダ

- `shared/` 地図・キャラ・兵種のデータ、合戦の計算、技の一覧（サーバーとブラウザで共通）
- `server/` ゲームの進行（`game.js`）、合戦（`battle.js`）、歴史イベントとエンディング（`events.js`）、日々のできごと（`incidents.js`）、地図のAI（`ai.js`・`demonai.js`）
- `public/` 画面
- `server.js` サーバー本体
