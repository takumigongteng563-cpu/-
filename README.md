# 魔王ヤギュー討伐戦（仮）

ブラウザで遊ぶ、2〜4人用のオンライン国取りゲーム。設計は [SPEC.md](SPEC.md)。

## 動かし方

Node.js 20 以上が必要（追加のインストールはなし）。

```
npm start
```

ブラウザで http://localhost:3000 を開く。

1. 名前を入れて「新しいゲームを作る」
2. 役（ヤギュー・スミレ・野口・七星）を選んで参加。**ヤギューとスミレは必須**、野口・七星は空いていればAI
3. 「ゲームを始める」

友だちと遊ぶときは、サーバーを動かしているPCのアドレス（例：`http://192.168.0.10:3000`）を開いてもらう。

ゲームは `data/` フォルダに自動で保存される。サーバーを止めても、次に起動すればロビーの「続きから」で再開できる。

## テスト

```
npm test            # ヤギューとスミレだけ（150日ぶん自動で進める）
node test/sim.js 150 all   # 4人ぶんを自動で進める
```

## フォルダ

- `shared/` 地図・キャラ・兵種のデータと、合戦の計算（サーバーとブラウザで共通）
- `server/` ゲームの進行（`game.js`）、合戦（`battle.js`）、歴史イベントとエンディング（`events.js`）
- `public/` 画面
- `server.js` サーバー本体
