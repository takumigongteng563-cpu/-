# 魔神野口と4人の勇者たち（Minecraft統合版アドオン）

普通の大学生4人がパラレルワールドに迷い込み、魔神野口と三魔将（菫・山羊・水牛）に挑む王道ファンタジーRPG。
Minecraft 統合版（Bedrock）専用。Nintendo Switch でのプレイを想定し、PC版から Realms 経由で導入します。

## 必要なもの

- Minecraft 統合版 **1.21.90 以降**（PC・Switch とも。Switch は本体のゲームを最新に更新してください）
- 導入作業用の **Windows PC 版 Minecraft（統合版）**
- Switch で遊ぶ場合：**Realms**（Realms の契約が必要）
- 実験的機能（ベータAPI）は**不要**です。安定版の Script API（`@minecraft/server 2.0.0` / `@minecraft/server-ui 2.0.0`）のみを使用しています。

## 導入方法

Switch 版はアドオンファイルを直接読み込めないため、PC で導入したワールドを Realms にアップロードして遊びます。

### 1. PC にアドオンを取り込む

1. `dist/MajinNoguchi_v0.3.0.mcaddon` を PC（またはスマホ）にダウンロードする
2. ファイルをダブルクリックする → Minecraft が起動し「インポートが完了しました」と表示される（ビヘイビアーパックとリソースパックの2つ）

### 2. ワールドを作る（PC）

1. 「新しく作成」→「新しいワールドを作成」
2. 左メニュー「ビヘイビアーパック」→「使用可能」から **魔神野口と4人の勇者たち BP** を選んで「有効にする」
   - リソースパックは依存関係により自動で有効になります（「リソースパック」に RP が入っていることを確認）
3. 管理コマンドを使う場合は「チート」を ON にする（任意。ON にすると実績は解除されなくなります）
4. 「作成」→ ワールドに入り、**「冒険者の書」を受け取ったこと**と、使うとメニューが開くことを確認する

### 3. Realms にアップロードする（PC）

1. ワールドを抜けてタイトルに戻る
2. 「遊ぶ」→「Realms」タブ → 自分の Realm の鉛筆アイコン（編集）
3. 「ワールドを置き換える」→ 手順2で作ったワールドを選ぶ
   - **置き換えると Realm の既存ワールドは上書きされます。** 既に遊んでいる Realm の場合、先に [バックアップ手順](docs/バックアップ手順.md) を行ってください
4. アップロード完了後、パックは Realm のワールドと一緒に保存されます

### 4. Switch から遊ぶ

1. Switch の Minecraft →「遊ぶ」→「Realms」→ Realm に参加
2. 初回はリソースパックのダウンロード確認が出るので「ダウンロード」を選ぶ
3. 参加するとチャットに歓迎メッセージが表示され、「冒険者の書」がインベントリに入ります

> Realms を使わない方法：PC でワールドを開いたまま、Switch から「フレンド」タブで PC のワールドに参加することもできます（PC を起動しておく必要があります）。

### v0.2.1 以前からの更新手順（v0.3.0）

**セーブデータはそのまま引き継がれます**（パックの UUID は同じ。職業の項目が自動で追加されます）。

1. **バックアップ**：Realm の場合は「ワールドをダウンロード」、手元のワールドは「ワールドをエクスポート」（[バックアップ手順](docs/バックアップ手順.md)）
2. `MajinNoguchi_v0.3.0.mcaddon` を取り込む（PC はダブルクリック、iPhone は「ファイル」アプリから手動でフォルダに入れる）
3. ワールドの編集 →「ビヘイビアーパック」でバージョンが **0.3.0** になっていることを確認（古いままなら一度無効にしてから 0.3.0 を有効にする）
4. ワールドに入り、`/scriptevent noguchi:status` で `v0.3.0` と表示されれば更新完了
5. Realm で遊ぶ場合は、そのワールドで Realm を「ワールドを置き換える」

v0.2.0 以前から直接 v0.3.0 に更新しても、下の v0.2.1 の移行も自動で行われます。

### v0.2.0（第2弾）・v0.1.0（第1弾）からの更新手順（v0.2.1・記録）

**セーブデータは自動で新しい形式に移行されます**（パックの UUID は同じです）。**移行は元に戻せないため、必ず先にバックアップしてください。**

1. **バックアップ**：Realm の場合は「ワールドをダウンロード」、手元のワールドは「ワールドをエクスポート」（[バックアップ手順](docs/バックアップ手順.md)）
2. `MajinNoguchi_v0.2.1.mcaddon` を取り込む（PC はダブルクリック、iPhone は「ファイル」アプリから手動でフォルダに入れる）
3. ワールドの編集 →「ビヘイビアーパック」で、有効なパックのバージョンが **0.2.1** になっていることを確認（古いままなら一度無効にしてから 0.2.1 を有効にする）
4. ワールドに入る。`/scriptevent noguchi:status` で `v0.2.1` と表示されれば更新完了
5. Realm で遊ぶ場合は、そのワールドで Realm を「ワールドを置き換える」

更新で変わること（詳細は [データ移行仕様](docs/データ移行仕様.md)）：
- 能力値が12種類になります（今までの値はそのまま、新しい4つは初期値5）
- **第2弾で初期才能を2個以上持っていた人は1個になります**（最初の1個が残り、残りは記録として保存）。全部残したい場合は、更新前に `packs/BP/scripts/balance/talentRoll.js` の `LEGACY_EXTRA_INNATE_POLICY` を `"keep"` に変えたパックを使ってください
- 第2弾で抽選された未覚醒の潜在能力は無効になり、今後は行動によって形成されます（覚醒済みのものは残ります）
- レベル・経験値・振り分け・金貨・設定などは変わりません

### 第1弾から第2弾への更新手順（記録）

**セーブデータはそのまま引き継がれます**（パックの UUID は第1弾と同じです）。

1. **必ず先にバックアップ**：Realm の場合は「ワールドをダウンロード」、手元のワールドは「ワールドをエクスポート」（[バックアップ手順](docs/バックアップ手順.md)）
2. `MajinNoguchi_v0.2.0.mcaddon` を取り込む（PC はダブルクリック、iPhone は「ファイル」アプリから手動でフォルダに入れる）
3. ワールドの編集 →「ビヘイビアーパック」で、有効なパックのバージョンが **0.2.0** になっていることを確認
   - 0.1.0 のままの場合は、一度無効にしてから 0.2.0 を有効にする
4. ワールドに入る。参加した全員に「あなたに宿る才能：……」と表示されれば更新完了（第1弾のプレイヤーは、このとき1回だけ初期才能が抽選されます）
5. Realm で遊ぶ場合は、そのワールドで Realm を「ワールドを置き換える」

金貨・設定・参加記録・ストーリー進行などの第1弾のデータは消えません。

### 既存ワールドへの導入

ワールドの「編集」→「ビヘイビアーパック」で有効にすれば、既存のワールドにも導入できます。
既存ワールドに入っていたプレイヤーも、次回参加時に初回扱いでデータが作成されます。

## 遊び方

- **冒険者の書**を手に持って「使う」（Switch：ZL／PC：右クリック／タッチ：長押し）と RPG 専用メニューが開きます
  - 空中に向けて使っても、ブロックに向けて使っても開きます
  - しゃがみとの組み合わせ操作は使いません
- 冒険者の書は捨てられず、死亡しても失われません。万一なくした場合は、再参加またはリスポーン時に自動で再配布されます
- メニュー項目：ステータス／職業／スキル／才能／装備／称号／クエスト／冒険者情報／ステージ情報／倉庫／設定
  - まだ中身がない機能には「今後実装予定」と表示されます
- **画面下（アクションバー）**に HP・MP・スタミナ・レベル・経験値・職業が表示されます（設定で非表示にできます）
- **レベル**：モンスターを倒すと経験値が入ります（第2弾ではバニラのモンスターで暫定対応）。レベルが上がると能力ポイントが5もらえます
- **能力ポイント振り分け**：冒険者の書 → ステータス → 能力ポイント振り分け。確定すると戻せないので、確認画面でよく見てから
- **才能**：初めて参加したときに1つの才能が宿ります。戦い方によって新しい才能が目覚めたり、才能が進化したりします
- **潜在能力**：最初は何もありません。戦い方や歩んできた道によって、本人も知らない力が形づくられ、条件を満たすと目覚めます
- **スタミナ**：ダッシュで減り、止まったりしゃがんだりすると早く回復します。0 になると少しの間、足が遅くなります
- **職業**：最初は無職です。レベル5になると、冒険者の書 → 職業 から **戦士・魔法使い・盗賊・僧侶** のどれにでもなれます（全員同じでもOK）
  - 職業にも「職業レベル」があり、その職業らしい戦い方をすると上がります（剣で戦う→戦士、回復→僧侶 など）
  - **職業融合**：職業レベルを上げ、別の系統の適性（例：魔力＋知力を振り分けで上げる）を満たすと、2つの職業を組み合わせた新しい職業になれます（例：戦士＋魔法 → 魔剣士、魔法使い＋戦士 → 戦魔導士）
  - 全部で484の職業があり、職業メニューの「職業融合ツリー」で系統ごとにたどれます。条件を満たした職業には「この職業に転職する」ボタンが出ます（転職の前に能力の比較と確認画面が出ます）
  - 一度なった職業には、いつでも職業レベルそのままで戻れます

## 管理者向け

管理者機能を使うには、チートを ON にして自分に管理者タグを付けます。

```
/tag @s add noguchi_admin
```

管理者には「設定」に **行動制限の設定**（ブロック破壊・設置・使用の禁止）、**最近のエラー**、**成長・余剰経験値の設定**、**テスト機能**（経験値付与・レベル設定・能力ポイント付与・HP/MP/スタミナ変更・才能付与・才能進化テスト・潜在能力覚醒テスト・限界突破テスト・ステータス再計算・セーブデータ確認・操作判定テスト・ステージクリア記録テスト・ワールド進行データ確認・**職業の無条件転職・職業レベル設定・職業経験値付与・転職の証付与・解放判定・職業データの自動検証**）が表示されます。一般プレイヤーには表示されません。
また、以下のコマンドが使えます（`/scriptevent` は権限のあるプレイヤーのみ実行可能）。

| コマンド | 内容 |
|---|---|
| `/scriptevent noguchi:menu` | メニューを開く |
| `/scriptevent noguchi:give_book` | 冒険者の書を受け取る（持っていない場合のみ） |
| `/scriptevent noguchi:save` | 全データを即時保存 |
| `/scriptevent noguchi:status` | データ状態をチャットに表示 |
| `/scriptevent noguchi:restrict <break\|place\|interact> <on\|off>` | 行動制限の切り替え |
| `/scriptevent noguchi:dump` | 自分の個人データをコンテンツログへ出力（PCでの外部バックアップ用） |
| `/scriptevent noguchi:dump_world` | ワールド共有データをコンテンツログへ出力 |

テスト用コマンド（プレイヤーが実行する場合は管理者タグが必要。最後にプレイヤー名を書くとその人が対象、省略時は自分）：

| コマンド | 内容 |
|---|---|
| `/scriptevent noguchi:exp <量> [名前]` | 経験値付与 |
| `/scriptevent noguchi:level <レベル> [名前]` | レベル設定（存在階級の上限まで） |
| `/scriptevent noguchi:points <数> [名前]` | 能力ポイント付与 |
| `/scriptevent noguchi:vital <hp\|mp\|stamina> <値> [名前]` | HP・MP・スタミナの変更 |
| `/scriptevent noguchi:talent <才能ID> [名前]` | 才能付与（IDは [才能一覧](docs/才能一覧.md)） |
| `/scriptevent noguchi:evolve <才能ID> [進化先ID] [名前]` | 才能進化テスト |
| `/scriptevent noguchi:awaken [潜在能力ID] [名前]` | 潜在能力覚醒テスト |
| `/scriptevent noguchi:limitbreak [名前]` | 限界突破テスト（条件を無視） |
| `/scriptevent noguchi:recalc [名前]` | ステータス再計算 |
| `/scriptevent noguchi:flag <フラグID> [名前]` | 特殊イベントのフラグを立てる |
| `/scriptevent noguchi:give_focus` | 操作判定の確認用アイテム「修練の触媒」を受け取る |
| `/scriptevent noguchi:input_test <on\|off>` | 操作判定テスト（修練の触媒を使うと判定結果を表示） |
| `/scriptevent noguchi:stage_clear <番号>` | ステージクリアの記録テスト（ステージ解放・章・王国の復興の確認） |
| `/scriptevent noguchi:job <職業ID> [名前]` | 無条件転職（例：`warrior.mage.mage`。IDは [職業一覧](docs/jobs/能力値一覧.md)） |
| `/scriptevent noguchi:joblevel <レベル> [名前]` | 現在の職業の職業レベル設定 |
| `/scriptevent noguchi:jobexp <量> [名前]` | 職業経験値付与 |
| `/scriptevent noguchi:jobtoken <個数> [名前]` | 「転職の証」（別系統への転職に使う）を付与 |
| `/scriptevent noguchi:jobcheck` | 職業データの自動検証 |

## 開発者向け

Node.js 20 以上が必要です（ゲーム自体の動作には不要）。

```bash
cd minecraft
npm install
npm run check
```

`npm run check` は次をまとめて実行します。

| コマンド | 内容 |
|---|---|
| `npm run validate` | パック構成の検証（JSON構文・UUID・BP/RP依存・import先の実在・アイコンと言語キー） |
| `npm run validate:jobs` | 職業データの自動検証（15項目）。結果を `docs/jobs/自動検証結果.md` に出力 |
| `npm run docs:jobs` | 職業の一覧資料（`docs/jobs/`）を生成 |
| `npm run typecheck` | 公式の型定義（`@minecraft/server@2.0.0`・`@minecraft/server-ui@2.0.0`）で全スクリプトを型チェック。存在しないAPIの使用を検出 |
| `npm test` | 単体テスト＋模擬エンジン上での統合テスト（ワールド再起動をまたぐ／第1弾のセーブデータからの更新） |
| `npm run build` | `dist/` に `.mcaddon` と `.mcpack` を作成 |

アイコン画像は `node devscripts/make-textures.mjs`、才能一覧は `node devscripts/talent-table.mjs` で再生成できます。
