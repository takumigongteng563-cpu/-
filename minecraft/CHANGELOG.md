# 変更点一覧

## v0.3.0（第3弾：全484職業・職業融合・転職システム）

仕様：[MASTER_SPEC.md](MASTER_SPEC.md) Ver.1.1 第9章。判断の記録：[docs/仕様変更履歴.md](docs/仕様変更履歴.md)。職業の一覧資料：[docs/jobs/](docs/jobs/)。

### 追加
- **全484職業**（第1次4・第2次12・第3次36・第4次108・第5次324）と職業融合ツリー。すべての職業に固有の名前・説明・役割・戦闘スタイル・得意武器・防具・得意属性・能力値補正・成長率・専用能力値・固有パッシブ・専用スキル・奥義（秘技）・強み・弱点・得意な場面・転職条件・引き継ぎ条件
- 第1次職業：戦士・魔法使い・**盗賊**・僧侶。第2次・第3次職業は指示書どおり
- **転職・職業融合**：主軸の職業＋融合する系統の適性で新しい職業が解放される（融合先の職業に転職する必要はない）。条件を満たしていない職業は選べない
- **職業レベル**（職業ごとに保存・戻ると引き継ぐ）・職業経験値（行動とプレイヤー経験値から）・職業レベルに応じた補正の成長
- **職業専用能力値12種**（剣気・闘気・守護力・魔力制御・精霊親和力・召喚力・弓術制御・隠密力・幻影制御・信仰力・治癒力・神聖力）。成長条件・上限・派生能力値への効果
- 引き継ぎパッシブ（極めた職業のパッシブを枠数まで）、専用スキルの引き継ぎ条件（第4弾で使用）
- 別系統への転職（特殊アイテム「転職の証」）、以前の職業への復帰
- **隠し職業の基盤**と検証用の隠し職業2種（発見するまで非表示）
- **職業メニュー**：現在の職業・職業Lv・経験値・特徴・専用能力値・補正、進化先3種、職業融合ツリー（系統→段階）、転職条件と達成状況、転職前後の能力比較、確認画面、履歴、引き継ぎ、職業スキル
- HUD に職業レベル、転職・職業融合・職業レベルアップ・職業の解放・隠し職業発見の演出
- 管理者テスト：無条件転職（ツリーから選択）・職業レベル設定・職業経験値付与・転職の証付与・解放判定・データの自動検証（コマンド：`job`・`joblevel`・`jobexp`・`jobtoken`・`jobcheck`）
- **職業データの自動検証**（15項目）と一覧資料の自動生成（名称一覧・融合ツリー・能力値・固有能力・スキル奥義予定・転職条件・検証結果）
- 条件の種類を追加：能力値・職業レベル・職業経験・系統の経験・行動の合計・ボス討伐・ステージ攻略・特殊アイテム・試練・称号・潜在能力・唯一装備・熟練度

## v0.2.1（最終基本仕様書 Ver.1.0 への対応修正）

仕様の正本：[MASTER_SPEC.md](MASTER_SPEC.md)。開発側の判断：[docs/仕様変更履歴.md](docs/仕様変更履歴.md)。データ移行：[docs/データ移行仕様.md](docs/データ移行仕様.md)。

### 旧仕様からの変更点
- **能力値 8種 → 12種**：生命力・持久力・集中力・統率力を追加（既存8種の値は維持、新4種は初期値5）。派生能力値に回復効果・疲労耐性・詠唱速度・詠唱妨害耐性・召喚/仲間補正を追加。HP回復は生命力、スタミナは持久力を主に参照するよう式を変更
- **能力値の成長上限**：存在階級ごとの上限（一般級100〜神級9999）。成長・振り分けは上限で止まり、限界突破で解放
- **職業系統の専用能力値**（剣気・闘気・守護力・魔力制御・召喚力・信仰力・隠密力）の基盤
- **初期才能 2～3個 → 全員1個**。生命力・持久力・集中力・統率力に関わる初期才能を4種追加（計44種）
- **潜在能力：開始時の抽選 → 行動による形成**（行動・職業系統・才能系統から形成。形成も覚醒条件も非公開）
- **経験値**：敵とのレベル差で増減（格上は増加・格下は減少）、限界突破するたびに必要経験値が増加、才能による経験値ボーナス（成長加速 +10%）
- **職業**：通常職業484枠（4系統×3分岐×5段階）のデータ構造。第1次職「戦士・魔法使い・斥候・僧侶」（暫定名）
- **ストーリー：全20章 → 全10章**。**ランダムダンジョン → 100固定ステージ**の管理基盤（ID・章・ボス枠・攻略方式・解放・記録）
- **富里王国**の復興データ（状態・住民・建物・施設）と、周回で重複しない移住・建設の処理
- **ホットバー複数操作**：9枠×5操作（通常・ジャンプ中・ダッシュ中・しゃがみ溜め・長時間溜め）の判定と割り当ての基盤。「しゃがみ操作を使わない」仕様を撤回
- **報酬**：個別抽選と周回補正（上限あり）の基盤。**世界唯一の装備**の管理基盤（譲渡・紛失・回復・複製検出・同時配布防止）
- メニュー「ダンジョン情報」→「ステージ情報」、「職業」「スキル」ページを新仕様の内容に更新
- 管理者テスト機能を追加：操作判定テスト、ステージクリア記録テスト、ワールド進行データ確認（コマンド：`give_focus`・`input_test`・`stage_clear`）
- 操作判定の確認用アイテム「修練の触媒」を追加（管理者テスト専用）
- 一時効果が職業専用能力値の補正を保持していなかった問題を修正

### データ
- プレイヤーデータ v2 → v3、ワールドデータ v1 → v2（自動移行。旧データは削除せず記録として保存）
- パックのバージョンを 0.2.1 に変更（UUID は変更なし）

## v0.2.0（第2弾：レベル・ステータス・才能）

### 追加
- **独自のレベル・経験値**（バニラの経験値とは別）
  - 経験値付与の共通処理 `ctx.progression.grantExp`（入手元：モンスター・ボス・ダンジョン・クエスト・特殊イベント・試練・管理者）
  - 余剰経験値の繰り越し、複数レベルの同時上昇、報酬キーによる二重付与防止、追いつき補正
  - 【暫定】バニラのモンスター討伐で経験値（ワールド設定で無効化可）
- **存在階級と限界突破の基盤**：一般級（上限50）〜神級（999）・未知の領域。突破条件は未実装のため通常は突破不可（管理者テストのみ）。上限到達後の余剰経験値は「保留／捨てる」を設定可能
- **能力値**：筋力・耐久・**魔力（新規）**・精神・敏捷・器用・幸運・知力の8種。基礎・成長・振り分け・才能・職業・装備・一時効果の層を別管理し、毎回ゼロから再計算（補正の重複なし）
- **派生能力値** 17種＋属性耐性8種（最大HP/MP/スタミナ・攻撃力・防御力・クリティカル・命中・回避・移動速度・回復量・積載・状態異常耐性）
- **HP・MP・スタミナ**：HP はバニラの体力と連動、MP の自然回復と消費の共通処理、スタミナのダッシュ消費・休息回復・疲労
- **自由能力振り分け**：1レベル5ポイント。1/5/10ずつ・1つ戻す・すべて取り消し・確認画面。確定後は戻せない（再振り分けの仕組みは将来用に用意）
- **成長率**：才能などによって能力ごとの自動成長が変わる（振り分けとは独立・上限あり）
- **先天性才能**：40種（F〜EX）。初回参加時のみ2〜3個を抽選、シード固定で引き直し不可
- **後天性才能**：14種。モンスターへの命中・討伐・被ダメージ・瀕死からの生還・移動距離などで目覚める（不正な稼ぎ対策あり）
- **才能進化**：枝分かれ進化（剣術適性 → 剣術の才 → 剣術の天才 → 剣聖の資質／剣術適性 → 魔剣適性 → 魔力剣術 → 魔剣の極致 など8種）
- **隠された潜在能力**：10種。覚醒するまで非公開。覚醒時は専用演出
- **メニュー拡張**：ステータス（概要・能力値の内訳・派生能力値・能力ポイント振り分け）、才能（等級・効果・進化の軌跡・潜在能力）
- **HUD**：アクションバーに HP・MP・スタミナ・レベル・経験値・職業（変化時と2秒ごとのみ更新）
- **管理者テスト機能**（メニュー・コマンド）：経験値付与・レベル設定・能力ポイント付与・HP/MP/スタミナ変更・才能付与・才能進化テスト・潜在能力覚醒テスト・限界突破テスト・ステータス再計算・セーブデータ確認
- 演出：レベルアップ・才能獲得・才能進化・潜在能力覚醒・限界突破（タイトル・効果音・パーティクル）
- 設定ファイル（`packs/BP/scripts/balance/`）：数値はすべてここで調整可能
- 開発：才能一覧の自動生成（`devscripts/talent-table.mjs`）、パックUUIDの変更検知、第1弾セーブデータからの更新テスト
