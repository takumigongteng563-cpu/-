## 属性の役割

| 属性 | 役割 | 付与する状態異常 | 弱点を突ける属性 |
|---|---|---|---|
| 火 | 火傷・継続ダメージ | 火傷 | 氷・植物・金属 |
| 水 | 水濡れ・属性連携 | 水濡れ | 火・爆発 |
| 風 | 機動力・吹き飛ばし | - | 地・毒 |
| 地 | 防御・体勢崩し | - | 雷・爆発 |
| 雷 | 麻痺・連鎖攻撃 | 感電・麻痺 | 水・金属 |
| 光 | 浄化・幻影への対抗 | - | 闇・精神 |
| 闇 | 呪い・視界妨害 | 呪い・暗闇 | 光・生命 |
| 無 | 属性に依存しない攻撃 | - | - |
| 氷 | 鈍化・凍結 | 鈍化・氷結 | 風・水 |
| 毒 | 継続ダメージ・回復妨害 | 毒・回復阻害 | 植物・生命 |
| 爆発 | 範囲攻撃 | - | 金属・地 |
| 金属 | 防御・貫通 | - | 氷・地 |
| 植物 | 拘束・再生 | 拘束 | 水・地 |
| 重力 | 移動制限・引き寄せ | 鈍化 | 風・空間 |
| 空間 | 転移・位置操作 | - | 重力・時間 |
| 時間 | 行動速度・クールタイム操作 | 鈍化 | 空間・生命 |
| 生命 | 回復・再生 | - | 深淵・毒 |
| 精神 | 混乱・恐怖 | 混乱・恐怖 | 雷・時間 |
| 神聖 | 浄化・魔物への特殊効果 | - | 深淵・闇 |
| 深淵 | 特殊妨害・弱体化 | 防御低下・属性耐性低下 | 神聖・精神 |
| 創造 | 結界・特殊物体生成 | - | 消滅・重力 |
