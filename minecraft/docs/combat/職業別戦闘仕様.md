# 職業別戦闘仕様（v0.5.0）

`npm run docs:combat` で自動生成。数値はすべて暫定（`balance/combat.js` で調整）。

| 役割 | 戦闘スタイル | 戦闘での仕組み（実装済み） | 職業数 |
|---|---|---|---:|
| 盾役 | タンク | 敵の攻撃を引きつけ、被ダメージの一部を軽減する | 75 |
| 近接火力 | 近接アタッカー | 連続で攻撃を当てるほど威力が上がる | 54 |
| 技巧（連撃・見切り） | 近接アタッカー | 見切って回避した直後の攻撃が必ずクリティカル | 22 |
| 射撃 | 遠距離アタッカー | 距離が離れているほど威力が上がる | 14 |
| 魔法火力 | 魔法アタッカー | 同じ属性の魔法を続けて使うと威力が上がる | 93 |
| 回復 | ヒーラー | 回復した量に応じて次の回復の効果が上がる | 51 |
| 支援 | バッファー | 強化を与えた仲間の数だけ自分も少し強くなる | 31 |
| 召喚 | 召喚職 | 召喚獣の強さが統率力に応じて上がる | 18 |
| 暗殺 | 近接アタッカー | 自分を狙っていない敵への攻撃が大ダメージになる | 29 |
| 妨害・制御 | デバッファー | 状態異常の効果時間が延びる | 34 |
| 遊撃 | 万能職 | 移動距離に応じて次の攻撃が強化される | 33 |
| 守護回復 | タンク | 仲間を守ったときに自分と周囲を回復する | 30 |

妨害職：妨害・制御の役割で盗賊系統を含む職業。特性は職業の段階で強くなる（×0.6+段階×0.2）。

## 職業専用能力値の戦闘効果

| 専用能力値 | 効果 | 上限 |
|---|---|---:|
| sword_aura | 剣技の威力 | +50% |
| battle_aura | 物理攻撃・体勢崩し | +40% |
| guard_power | ガード軽減 | +20% |
| mana_control | 魔法の威力 | +50% |
| spirit_affinity | 属性攻撃 | +40% |
| summon_power | 召喚獣 | +60% |
| bow_control | 射撃の威力 | +50% |
| stealth | 不意打ち | +40% |
| illusion_control | 状態異常の確率 | +30% |
| faith | 神性・加護 | +30% |
| healing_power | 回復量 | +50% |
| holy_power | 神聖属性 | +60% |
