# 戦闘操作マニュアル（v0.5.0）

| 行動 | 操作（Switch 初期設定） | 効果 |
|---|---|---|
| 通常攻撃 | ZR（武器で攻撃） | 続けて当てるとコンボ（同じ技は2回まで） |
| 技・魔法 | 技の触媒を持って ZL（通常／ジャンプ中／ダッシュ中／しゃがみ溜め／長時間溜め） | 9枠×5操作 |
| ガード | しゃがむ（Rスティック押し込み） | 軽減・スタミナ消費 |
| ジャストガード | 攻撃を受ける直前0.3秒以内にしゃがむ | 9割軽減・敵の体勢を崩す・反撃2秒 |
| 回避 | ダッシュ中にジャンプ（または移動技） | 0.4秒無敵・1.2秒の再使用待ち・スタミナ15 |
| ジャスト回避 | 攻撃の直前0.2秒以内に回避 | 行動速度上昇・反撃2秒 |
| 反撃 | ジャストの後2秒以内に攻撃 | 1.5倍（技巧の職業は必ず会心） |
| 属性融合 | 別の属性の攻撃の直後に組み合わせの属性で攻撃 | 範囲の追加効果 |
| 連携 | 仲間の技の直後に連携スキル | 威力アップ |

- 強い攻撃の前には地面の輪・効果音・攻撃名が表示されます。範囲から出るか、ジャスト回避・ジャストガードで防げます
- HUD：溜め・詠唱 → 自分の状態異常 → 攻撃中の敵（HP・属性・発見した弱点・状態異常・体勢）→ 危険な仲間（最大3行）
- 戦闘の結果：冒険者の書 → スキル → 戦闘ログ（直近5戦・戦闘不能の原因）
- 判定時間などは `balance/combat.js` で調整できます。**Switch実機でのタイミングは未検証**です
