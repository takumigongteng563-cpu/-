# ダメージ計算式（v0.5.0）

`npm run docs:combat` で自動生成。数値はすべて暫定（`balance/combat.js` で調整）。

処理の順番（`combat/damageCalc.js`）：

1. 基礎攻撃力（物理＝物理攻撃力、魔法・属性＝魔法攻撃力。固定＝指定値、割合＝最大HP×割合）
2. スキル倍率（スキルの威力式 ÷ 10）
3. 武器性能（通常攻撃はバニラの武器ダメージ。装備は第6弾）
4. 職業補正（職業専用能力値）
5. 才能補正
6. 熟練度補正（スキルLv1ごと+2%・最大+40%）
7. 防御：ダメージ × 攻撃 ÷（攻撃 ＋ 防御×1×分類の防御率）
8. 属性相性（複数属性は平均・上限2）
9. クリティカル（倍率上限3）
10. 部位弱点×1.3・体勢崩し中×1.5
11. バフ・デバフ（攻撃側−90%〜+200%、受ける側−80%〜+200%）
12. 神々の加護（0.5〜2倍）
13. 特殊効果（コンボ・反撃・連携・役割の仕組み。0〜4倍）
14. 上限（基礎の8倍・1回99999、固定・割合は敵ごとの上限）

最後に「戦闘の数値 × 0.1 ÷ 参加人数の補正」をバニラの体力に与える。バニラの攻撃で入った分との差分だけを調整するため二重に入らない。

## ダメージ分類

| 分類 | 防御 | 防御率 | 会心 | 属性 | 上限 |
|---|---|---:|---|---|---|
| 物理 | def | 1 | あり | あり | - |
| 魔法 | mdef | 1 | あり | あり | - |
| 属性 | mdef | 0.8 | あり | あり | - |
| 固定 | なし | 0 | なし | なし | 敵ごと（fixed） |
| 貫通 | def | 0.3 | あり | あり | - |
| 継続 | なし | 0 | なし | あり | - |
| 反射 | なし | 0 | なし | なし | - |
| 割合 | なし | 0 | なし | なし | 敵ごと（percent） |
| 神性 | mdef | 0.5 | あり | あり | - |
| 特殊 | なし | 0 | なし | あり | - |
