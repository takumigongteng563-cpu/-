# バックアップ手順

## アドオン内部で行っていること

- 個人データ・ワールドデータはそれぞれ **2つの保存枠に交互に保存**し、1つ前の状態を常に残しています
- 破損を検知すると自動で1つ前の状態から復旧します
- 両方とも壊れていた場合は、壊れたデータを別の場所に**退避**してから初期化します（退避データは管理者・開発者が後から調べられます）

ただし、これらは**ワールドの中**に保存されているため、ワールドそのものが失われた・壊れた場合には役に立ちません。
**ワールド単位のバックアップは、アドオンの中からは作れません。** 以下の手順で外部に保存してください。

---

## Realms のバックアップ（推奨）

Realms は定期的に自動バックアップを作成しています。

### Realm のバックアップから復元する
1. PC または Switch で「遊ぶ」→「Realms」→ Realm の編集（鉛筆アイコン）
2. 「バックアップ」（または「ワールドのバックアップ」）を開く
3. 戻したい日時のバックアップを選び「復元」

### Realm のワールドを PC にダウンロードして保管する（アップデート前は必須）
1. PC 版で Realm の編集 →「ワールドをダウンロード」
2. ダウンロードしたワールドが PC の「ワールド」一覧に追加される
3. 下の「PC のワールドを保存する」の手順で `.mcworld` にエクスポートして保管

## PC のワールドを保存する

### 方法A：ワールドのエクスポート（いちばん簡単）
1. 「遊ぶ」→「ワールド」→ 対象ワールドの鉛筆アイコン（編集）
2. 下の方の「ワールドをエクスポート」→ 保存先を選ぶ
3. `ワールド名.mcworld` ファイルができる（アドオンのパックも一緒に含まれます）
4. 戻すときは `.mcworld` をダブルクリックすると、別のワールドとして取り込まれる

### 方法B：ワールドフォルダをコピー
ワールドフォルダをまるごとコピーします。保存場所は Minecraft のバージョンによって異なります。
- 新しい版：`%APPDATA%\Minecraft Bedrock\Users\（ユーザーID）\games\com.mojang\minecraftWorlds\`
- 古い版：`%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds\`

フォルダ名はランダムな文字列です。中の `levelname.txt` でワールド名を確認してください。
コピーは **Minecraft を終了した状態** で行ってください。

## Switch 本体のワールド

Switch 本体に保存したワールドはファイルとして取り出せません。Switch で遊ぶ場合は Realms を使い、上の Realms の手順でバックアップしてください。

## 個人データだけを書き出す（PC・調査用）

PC 版でコンテンツログを有効にしている場合、次のコマンドでデータを JSON 文字列としてログに出力できます。

```
/scriptevent noguchi:dump
/scriptevent noguchi:dump_world
```

コンテンツログファイル（PC のログフォルダ）に `[魔神野口][DUMP]` で始まる行として出力されます。
長いデータは複数行に分割され、行頭の `[1/3]` のような番号順につなげると元の JSON になります。
※ 現時点ではこの JSON をゲームに読み戻す機能はありません（調査・記録用）。

## アップデート時の手順

1. **必ず**ワールド（Realm の場合はダウンロードしたもの）を `.mcworld` でエクスポートして保管する
2. 新しいバージョンの `.mcaddon` を PC に取り込む
3. ワールドの編集 → ビヘイビアーパックが新しいバージョンになっていることを確認
4. 一度 PC で入り、コンテンツログにエラーがないこと、データが維持されていることを確認
5. Realm に「ワールドを置き換える」でアップロード
