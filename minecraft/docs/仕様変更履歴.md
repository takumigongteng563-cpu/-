# 仕様変更履歴

[MASTER_SPEC.md](../MASTER_SPEC.md)（最終基本仕様書 Ver.1.0）を最優先とし、追加決定・仕様変更・実装上の判断をここに記録します。
「判断」は開発側で決めた暫定事項です。企画側で変更する場合は、この表に追記してから実装を変えてください。

## 2026-11-26 最終基本仕様書 Ver.1.0 を受領（v0.2.1）

### 仕様の変更（指示書による）

| # | 旧仕様（第1弾・第2弾） | 新仕様（Ver.1.0） |
|---|---|---|
| 1 | メインストーリー全20章 | 一本道・全10章 |
| 2 | ダンジョン200種・ランダム生成の想定 | 100固定ステージ（ランダム生成は廃止） |
| 3 | 基本能力値8種 | 12種（生命力・持久力・集中力・統率力を追加）＋職業系統の専用能力値 |
| 4 | 初期才能2～3個 | 全員1個 |
| 5 | 潜在能力は初回参加時に抽選・固定 | 行動・職業・戦闘スタイル・攻略実績から形成 |
| 6 | 職業400種以上 | 通常職業484（4系統×3分岐×5段階）＋隠し職業 |
| 7 | しゃがみ＋アイテム使用の操作は使わない | 撤回。ホットバー9枠×5操作（通常／ジャンプ中／ダッシュ中／しゃがみ溜め／長時間溜め） |
| 8 | 経験値は入手元ごとの倍率のみ | 格上の敵は増加・格下は減少、限界突破ごとに成長が難しくなる、才能・職業で成長速度が変わる |
| 9 | 存在階級に「未知の領域」 | 神級（999）まで |
| 10 | 能力値に上限なし（全体の最大値のみ） | 能力値に成長上限。限界突破で解放 |

### 実装上の判断（開発側で決めた暫定事項）

| # | 項目 | 判断 | 理由 |
|---|---|---|---|
| D1 | 新しい4能力値のID | 生命力 `lif`／持久力 `endr`／集中力 `foc`／統率力 `lead`。初期値はいずれも 5 | 既存8能力値と同じ「一般人相当」。IDは保存データに残るため以後変更しない |
| D2 | 能力値の成長上限 | 存在階級ごとの暫定値：一般級100・超人級250・英雄級500・伝説級1000・神話級2500・半神級5000・神級9999。対象は「基礎＋成長＋振り分け」。才能・装備などの補正は上限の外 | 補正まで含めると装備の価値がなくなるため。`balance/progression.js` で変更可能 |
| D3 | 限界突破ごとの必要経験値 | 存在階級ごとの倍率：1.0／1.3／1.6／2.0／2.5／3.0／4.0 | 「限界突破するたびに成長が難しくなる」 |
| D4 | 敵とのレベル差による経験値 | 倍率 = 1 + (敵Lv − 自分Lv) × 0.08、0.1～2.0倍 | 格上は増加・格下は減少。弱い敵を延々と倒す稼ぎの効率を下げる |
| D5 | 第2弾で2～3個の初期才能を得ていた人 | **最初の1個だけを有効**にし、残り（進化後のものを含む）は `talents.archived` に移して無効化。**削除はしない**。`LEGACY_EXTRA_INNATE_POLICY` を `"keep"` にすると全部残せる | 「全員1個」に合わせて4人の公平性を保つため。既存データ削除の禁止に従い、記録として保持 |
| D6 | 第2弾で抽選された潜在能力 | 未覚醒のものは `legacy` として無効化（記録は保持）。**覚醒済みのものは有効のまま** | 抽選方式は廃止だが、すでに得た成長は失わせない |
| D7 | 潜在能力の形成方法 | 行動回数・職業系統・才能系統から形成スコアを計算し、しきい値（30 × (形成済み数+1)）を超えたものを形成。最大3つ。形成も本人には非公開 | 「行動によって形成」「覚醒まで名前・条件を非公開」 |
| D8 | 「未知の領域」 | データ上は予備の段階として残す（突破条件なし＝到達不可） | 第2弾で作成した段階の削除を避けるため。Ver.1.0 の存在階級は神級まで |
| D9 | 「ダンジョン情報」メニュー | 「ステージ情報」に変更（メニュー内の位置は同じ） | ランダムダンジョン廃止のため。ワールドデータの旧ダンジョン項目は削除せず「旧仕様・未使用」として残す |
| D10 | ストーリーの章 | 旧データの章番号は `story.legacyChapter` に残し、新しい章を 1～10 に収める。今後はステージの進行から章を決める | 全20章 → 全10章 |
| D11 | 職業ID | ツリー上の位置で決める（例：`warrior.a.b`）。名前は後から決めてもIDが変わらない | 484職業の名前が未定のため |
| D12 | ステージID | `stage001`～`stage100` | 保存データに残るため固定 |
| D13 | 操作の優先順位 | 奥義（長時間溜め）＞大技（しゃがみ溜め）＞移動技（ダッシュ中）＞中技（ジャンプ中）＞小技（通常）。しゃがまずに中途半端な長さで押して離した場合は**不発**（誤発動防止） | 競合時の扱いを一意に決めるため |
| D14 | 溜めの測り方 | 「押し続けた時間」（使用時間のあるアイテムのみ）と「しゃがみ続けた時間」の長い方を溜めとする | Switch で長押しの判定ができるかは実機確認が必要なため、しゃがみ時間による溜めを代替として併用（[Switch検証状況](Switch検証状況.md)） |
| D15 | 操作判定の確認用アイテム | 「修練の触媒」（`noguchi:skill_focus`）。管理者テスト専用 | スキル本体（第4弾）が無い段階で操作判定を実機確認するため |
| D16 | 唯一装備の複製防止 | 配布・譲渡・回復のたびに通し番号（instanceId）を更新し、アイテム側に記録した番号と照合（照合の実装は第6弾） | ワールドに1つだけ存在することを保証するため |
| D17 | 真の黒幕に関する情報 | MASTER_SPEC.md のみに記載し、パック（ゲームに入るファイル）には書かない | 本編クリアまで明かさないため |
| D18 | 経験値ボーナス（才能など） | 合計 +50% まで | 極端な成長を防ぐ |
| D19 | 報酬の周回補正 | クリア1回ごとに +2%、上限 +30%。幸運は 5 を超えた1ポイントごとに +1%、上限 +50%。当選確率の上限 95% | 「周回補正には上限を設ける」。`balance/rewards.js` で変更可能 |
| D20 | 第2弾のメニュー・操作 | 冒険者の書の操作（使用でメニュー）は変更なし | しゃがみ操作の撤回は技の操作に関するもの |
