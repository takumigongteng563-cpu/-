## 1. レベル計算式

```
次のレベルまでの必要経験値(L) = round( 40 × L^1.5 + 60 × L )
```

| レベル | 必要経験値 | 到達までの累計 |
|---|---:|---:|
| 1 → 2 | 100 | 100 |
| 2 → 3 | 233 | 333 |
| 5 → 6 | 747 | 2,028 |
| 10 → 11 | 1,865 | 9,007 |
| 20 → 21 | 4,778 | 43,033 |
| 30 → 31 | 8,373 | 110,086 |
| 49 → 50 | 16,660 | 349,308 |
| 50 → 51 | 17,142 | 366,450 |
| 99 → 100 | 45,342 | 1,877,055 |
| 150 → 151 | 82,485 | 5,125,386 |
| 200 → 201 | 125,137 | 10,313,606 |
| 300 → 301 | 225,846 | 27,754,540 |
| 500 → 501 | 477,214 | 97,181,448 |
| 998 → 999 | 1,320,998 | 533,979,184 |

- 必要経験値はレベルとともに増えますが、指数関数ではなく「レベルの1.5乗」なので、序盤は上がりやすく、終盤ほど多く必要になります。
- **【最終仕様】限界突破するたびに成長が難しくなる**：上の表は一般級の値です。存在階級ごとに必要経験値に倍率が掛かります（下の「存在階級」の表）。
- **【最終仕様】格上の敵は経験値が増え、格下は減る**：`倍率 = 1 + (敵のLv − 自分のLv) × 0.08`（0.1〜2.0倍）。敵のレベルが分かる入手元（モンスター・ボス）にだけ適用します。バニラのモンスターには暫定のレベル（ゾンビ3〜ウォーデン45）を設定しています。
- **【最終仕様】才能などで成長速度が変わる**：才能・職業などの `expBonus` を合計して経験値に加算（合計 +50% まで）。例：成長加速 +10%。
- 経験値の量は、後続で追加する強いモンスター・ボス・ダンジョン・クエストの報酬が大きくなる前提です。弱い敵を延々と倒させる設計にはしません。
- **余剰経験値の繰り越し**：レベルアップで余った分は次のレベルに持ち越します。一度に大量に得た場合は、まとめて複数レベル上がります。
- **二重付与の防止**：報酬ごとにキー（例：`kill:<エンティティID>`、`quest:<ID>`）を付けて記録します。同じキーの報酬は二度と受け取れません。`once` を付けた報酬は永久に1回だけです。
- **追いつき補正**：オンラインの最高レベルより4以上低いプレイヤーは、差1につき +5%（最大2倍）の経験値を得ます。後から参加した人や才能に恵まれなかった人が、単調な稼ぎをしなくても追いつけるようにするためです。
- **不在プレイヤー**には経験値を付与しません（オフラインへの付与は失敗します）。

### 経験値の入手元（共通処理 `ctx.progression.grantExp`）

| source | 入手元 | 第2弾での状態 |
|---|---|---|
| `monster` | モンスター討伐 | **暫定でバニラのモンスターに対応**（ゾンビ10〜ウォーデン1500など。管理者が無効化可） |
| `boss` | ボス討伐 | 共通処理のみ（ボス実装時に使用） |
| `dungeon` | ダンジョンクリア | 共通処理のみ |
| `quest` | クエスト達成 | 共通処理のみ |
| `event` | 特殊イベント | 共通処理のみ |
| `trial` | 試練達成 | 共通処理のみ |
| `admin` | 管理者付与 | テスト機能 |

## 2. 存在階級とレベル上限

| 段階（限界突破回数） | 存在階級 | レベル上限 | **【最終仕様】能力値の成長上限** | **【最終仕様】必要経験値の倍率** | 突破条件 |
|---:|---|---:|---:|---:|---|
| 0 | 一般級 | 50 | 100 | 1.0 | 未実装 |
| 1 | 超人級 | 100 | 250 | 1.3 | 未実装 |
| 2 | 英雄級 | 150 | 500 | 1.6 | 未実装 |
| 3 | 伝説級 | 200 | 1,000 | 2.0 | 未実装 |
| 4 | 神話級 | 300 | 2,500 | 2.5 | 未実装 |
| 5 | 半神級 | 500 | 5,000 | 3.0 | 未実装 |
| 6 | 神級 | 999 | 9,999 | 4.0 | 未実装 |
| 7 | 未知の領域（予備・到達不可） | 999 | 99,999 | 5.0 | なし |

- **【最終仕様】能力値の成長上限**：「基礎＋成長＋振り分け」の合計の上限。上限に達した能力値は自動成長も振り分けもできません。才能・装備などの補正は上限の外です。限界突破で上限が上がります。
- **【最終仕様】勇者ごとに異なる突破条件**：階級共通の条件に加え、プレイヤーのデータ（才能・職業など）に応じた追加条件を `PERSONAL_BREAK_REQUIREMENTS` に書けるようにしました（第13弾で定義）。

- 突破条件（`requirements`）が未定義の階級は、**通常の操作では突破できません**。管理者テストの「限界突破テスト」だけが条件を無視できます。
- 上限に達した後の余剰経験値はワールド設定で選べます。
  - **保留**（初期値）：上限レベルの必要経験値×3まで貯め、限界突破したときに加算
  - **捨てる**

## 3. 能力値の計算

### 層ごとの管理

能力値は次の層に分けて保存・計算し、合計は保存しません。**再計算は毎回ゼロから行うため、補正が重複して加算されることはありません。**

| 層 | 保存場所 | 内容 |
|---|---|---|
| 基礎 | `stats` | 初期値（全12能力5） |
| 成長 | `statGrowth` | レベルアップ時の自動成長（成長率による） |
| 振り分け | `statAllocated` | 自由振り分けで確定した分 |
| 才能 | 才能・潜在能力の定義から計算 | 先天・後天・進化・覚醒した潜在能力 |
| 職業 | 職業の定義から計算 | 第3弾で使用（無職は補正なし） |
| 装備 | 装備データから計算 | 装備システム実装後に使用 |
| 一時効果 | `buffs` | 期限付き。同じIDは上書き（重ねがけ不可） |

### 計算順序

```
0. 素の値 = 基礎 + 成長 + 振り分け を、存在階級の能力値上限までに制限【最終仕様】
1. 固定値の合計 = 素の値 + 才能 + 職業 + 装備 + 一時効果
2. 割合補正の合計 = すべての層の % 補正の合計 を [-50%, +200%] に制限
3. 能力値 = floor( 固定値の合計 × (1 + 割合補正 / 100) ) を [0, 99,999] に制限
4. 派生能力値 = 下表の式
5. 派生能力値 = (式の値 + 派生の固定値補正) × (1 + 派生の割合補正 / 100) を項目ごとの範囲に制限
```

### 派生能力値の式

`Δ能力` = その能力値 − 初期値（5）、`Lv-1` = レベル − 1。初期状態（全能力5・Lv1）では「基本値」になります。

| 派生能力値 | 基本値 | 計算式（基本値に加算） | 範囲 |
|---|---:|---|---|
| 最大HP | 100 | 耐久×12 + 筋力×2 + (Lv-1)×5 | 1〜 |
| 最大MP | 50 | 魔力×8 + 知力×3 + (Lv-1)×2 | 0〜 |
| 最大スタミナ | 100 | **持久力×6** + 耐久×2 + 敏捷×2 + (Lv-1)×1 | 10〜99,999 |
| 物理攻撃力 | 10 | 筋力×2 + 器用×0.5 + (Lv-1)×1 | 0〜 |
| 魔法攻撃力 | 10 | 魔力×2 + 知力×0.5 + (Lv-1)×1 | 0〜 |
| 物理防御力 | 5 | 耐久×1.5 + 筋力×0.3 + (Lv-1)×0.5 | 0〜 |
| 魔法防御力 | 5 | 精神×1.5 + 魔力×0.3 + (Lv-1)×0.5 | 0〜 |
| クリティカル率 | 5% | 器用×0.2 + 幸運×0.1 | 0〜75% |
| クリティカル倍率 | 1.5倍 | 器用×0.005 | 1〜3倍 |
| 命中率 | 90% | 器用×0.3 | 10〜100% |
| 回避率 | 5% | 敏捷×0.2 + 幸運×0.05 | 0〜60% |
| 移動速度 | 1.0倍 | 敏捷×0.004 | 0.5〜1.5倍 |
| HP自然回復（5秒） | 1 | **生命力×0.3** + 耐久×0.05 + (Lv-1)×0.05 | 0〜 |
| MP自然回復（5秒） | 2 | 精神×0.2 + 知力×0.1 + (Lv-1)×0.05 | 0〜 |
| スタミナ回復（5秒） | 10 | **持久力×0.5** + 敏捷×0.1 | 1〜 |
| 最大積載重量 | 50 | 筋力×5 | 1〜 |
| 状態異常耐性 | 0% | 精神×0.5 | 0〜80% |
| **【最終仕様】回復効果** | 100% | 生命力×1 + 精神×0.3 | 0〜1000% |
| **【最終仕様】疲労耐性** | 0% | 持久力×0.5 | 0〜80% |
| **【最終仕様】詠唱速度** | 100% | 集中力×1 | 50〜300% |
| **【最終仕様】詠唱妨害耐性** | 0% | 集中力×0.6 + 精神×0.2 | 0〜90% |
| **【最終仕様】召喚・仲間補正** | 100% | 統率力×1.5 | 0〜1000% |
| 属性耐性（火・水・風・土・雷・氷・光・闇） | 0% | 才能などの補正の合計 | -100〜75% |

（表の「能力名×係数」はすべて Δ能力 に掛けます。HP・MP・スタミナ・攻撃・防御・積載は整数に切り捨て、それ以外は小数第2位まで。）

第2弾では、攻撃力・防御力・命中・回避・移動速度・積載重量・耐性は**計算・保存・参照できる状態**です。戦闘や重量管理への実際の反映は後続の戦闘システム等で行います。

## 4. HP・MP・スタミナ

| | 仕様 |
|---|---|
| HP | **バニラの体力を唯一の基準**とし、`HP = 最大HP × (体力 ÷ 体力の最大値)` で表示・保存。ダメージはバニラ側で1回だけ処理されるため二重に適用されません。死亡もバニラのまま。リスポーンで全回復。自然回復は5秒ごとに「HP自然回復」をバニラの体力に換算して加算（バニラの満腹度回復とは別） |
| MP | 5秒ごとに「MP自然回復」だけ回復。スキル用の共通処理 `ctx.vitals.trySpend(id, {mp, stamina})` は、足りなければ何も消費せず失敗します |
| スタミナ | ダッシュ中は毎秒8消費。止まっている・しゃがみ・睡眠中は「スタミナ回復」の2.5倍、歩行中は1倍で回復。0になると「疲労」（最大値の25%まで回復すると解除）。疲労中の制限はワールド設定：移動低下（鈍化Lv2を短時間付与）／制限なし |

レベルアップ時は HP・MP・スタミナを全回復します（設定で無効化可）。

## 5. 自由能力振り分け

- 1レベル上がるごとに **5ポイント**（`STAT_POINTS_PER_LEVEL`）
- メニュー：冒険者の書 → ステータス → 能力ポイント振り分け
  - 能力値ボタンを押すたびに「増やす量」（1 / 5 / 10 で切り替え）だけ追加
  - 「1つ戻す」「すべて取り消し」で確定前なら取り消せる
  - 「確定する」→ 確認画面（振り分け前後の値）→ 確定
- 確定済みの振り分けは戻せません。再振り分けは `respecTokens`（将来の特殊アイテム・試練で付与）を1消費して行う関数 `respec()` を用意済み（通常のメニューからは呼べない）
- 確定時に未使用ポイントを改めて確認するため、同時操作や二重押しでもポイントが不足・マイナスになりません

## 6. 成長率

```
レベル1上昇ごとの自動成長 = 基本成長率 × 成長率倍率
成長率倍率 = 1 + clamp( 才能・潜在能力・職業・称号・装備の成長率補正の合計, -0.5, +1.5 )
```

| 能力 | 筋力 | 耐久 | 魔力 | 精神 | 敏捷 | 器用 | 幸運 | 知力 | 生命力 | 持久力 | 集中力 | 統率力 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 基本成長率（/Lv） | 0.5 | 0.5 | 0.5 | 0.5 | 0.5 | 0.5 | 0.25 | 0.5 | 0.5 | 0.5 | 0.4 | 0.3 |

- **【最終仕様】** 能力値が成長上限に達している場合、その能力値は成長しません。

- 小数部分は能力ごとに貯め、1を超えた分だけ能力値が上がります（乱数なし。同じ才能・同じレベルなら同じ結果）。
- 例：斧術適性（筋力成長+10%）なら、レベル41時点で筋力の成長分は `0.5 × 1.1 × 40 = 22`。
- **成長率補正と自由振り分けポイントは完全に独立**しています（成長は `statGrowth`、振り分けは `statAllocated`）。
- 補正がいくつ重なっても +150% / −50% を超えません。
- 成長はレベルが上がった時点の補正で計算します（後から才能が増えても、過去の成長は変わりません）。

## 7. 才能

詳細な一覧・確率・効果は **[才能一覧](才能一覧.md)**（自動生成）を参照してください。

| 種類 | 数 | 入手方法 |
|---|---:|---|
| 初期才能 | 44 | **【最終仕様】初回参加時に全員1個**を抽選（第1弾から更新したプレイヤーも1回だけ抽選。第2弾で2個以上得た人は1個に移行） |
| 後天性才能 | 14 | 行動・実績の条件を満たすと1回だけ獲得 |
| 進化で得る才能 | 8 | 才能の進化 |
| 隠された潜在能力 | 10 | **【最終仕様】開始時は未確定。行動・職業・戦い方から形成**（非公開）。行動・実績・試練・特殊イベントで覚醒 |

### 等級の確率（1枠あたり）

| F | E | D | C | B | A | S | SS | SSS | EX |
|---|---|---|---|---|---|---|---|---|---|
| 30% | 25% | 18% | 12% | 7% | 4.5% | 2.4% | 0.8% | 0.25% | 0.05% |

### 才能の定義項目

固有ID・名前・説明・等級・抽選確率（等級確率×重み）・能力値補正・派生能力値補正・属性耐性・成長率補正・職業適性・スキル習得への影響・覚醒条件・進化先（複数・優先度つき）。書き方は `content/talents/schema.js`。

### 抽選のやり直し防止

抽選結果と「抽選済み」の印は即時保存されます。乱数はプレイヤーごとのシードから作るため、仮に抽選処理が再実行されても同じ結果になります。再ログイン・死亡・ワールド再起動で引き直されることはありません。

### 低等級でも強くなれる設計

- 強さの大部分はレベル（成長）と自由振り分け（1レベル5ポイント）で決まり、これは才能に関係なく全員同じです。
- 才能の割合補正は全体の上限があり、成長率補正も +150% が上限です。
- 低等級の才能（F）にも進化先があり、使い続ければ S 等級まで進化します。
- 才能がない系統でも、行動によって後天性才能が目覚め、同じ進化の道に合流します（例：剣の心得 → 剣術の才）。
- 追いつき補正で、レベル差も縮まります。

### 後天性才能の不正獲得対策

- 数えるのは**モンスター（family: monster）への実際の命中・討伐**だけです。空振り・動物・防具立て・プレイヤーへの攻撃は数えません。
- 1人あたり4tick未満の連続命中は数えません。同じ1体への命中は40回までしか数えません。
- 討伐は同じエンティティを二度数えません。
- 移動距離はテレポート等の大きな移動を含めません。放置では増えません。
- 一度獲得した後天性才能は、条件を満たし続けても二度と獲得しません。

### 進化

- `evolvesTo` に複数の進化先を書け、`priority` の大きい順に条件を判定し、最初に満たしたものへ進化します。
- 進化すると元の才能は置き換わり、進化の軌跡（`lineage`）が残ります。
- 1回の判定で進むのは1段階までです。

### 【最終仕様】潜在能力の形成

- 開始時点では潜在能力はありません。
- 行動の記録（攻撃・討伐・被ダメージ・瀕死からの生還・移動距離・魔法・回復・仲間の防御・ステージクリアなど）、現在の職業の系統、所持している才能の系統から、潜在能力ごとの「形成スコア」を計算します。
- 最も高いスコアが「30 × (形成済みの数 + 1)」以上になると、その潜在能力が形成されます（最大3つ）。剣で戦い続けた人と、魔物を狩り続けた人では、形成される潜在能力が変わります。
- 形成されたことも、名前も、覚醒条件も、覚醒するまで本人には表示しません（才能画面に「何かが形になりつつある」とだけ表示）。
- 形成スコアの計算元は [才能一覧](才能一覧.md) の潜在能力の表を参照（開発者向け）。

### 潜在能力の非公開

形成された潜在能力はプレイヤーデータに保存されていますが、才能画面には「何かが形になりつつある」とだけ表示し、名前・効果・条件は覚醒するまで表示しません。覚醒時は専用のタイトル表示・効果音（トーテム・雷鳴）・パーティクル・全体メッセージで演出します。

## 8. HUD

アクションバー（統合版標準の表示）に次の2行を表示します。

```
HP 100/100  MP 50/50  ST 100/100
Lv 1  EXP 0/100  無職  +5pt
```

- 0.5秒ごとに内容を確認し、**変化があったときだけ**再表示。変化がなくても2秒ごとに表示し直します（アクションバーは数秒で消えるため）。
- ほかの通知（行動制限の警告など）を出したときは3秒間（保存通知は1秒間）HUD を止めます。
- 設定 → 個人設定 で HUD を非表示にできます。
