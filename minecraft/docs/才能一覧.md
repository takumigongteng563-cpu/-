# 才能一覧（自動生成）

`node devscripts/talent-table.mjs` で生成。手で編集しないこと（定義は `packs/BP/scripts/content/talents/` と `content/potentials.js`）。

## 初期才能の抽選方法

1. 才能の数：必ず 2 個。さらに 25% の確率で 1 個追加（最大 3 個）
2. 1 枠ごとに等級を抽選（下表の確率）。その等級に候補がなければ近い等級から選ぶ
3. その等級の初期才能から、才能ごとの重み（weight）で 1 つ選ぶ。同じ系統（family）の才能は重複しない
4. 乱数はプレイヤーごとのシード（初回参加時に決定・保存）から作るため、何度やり直しても結果は同じ。抽選は初回参加時の 1 回のみ

| E | 下級 | 25% | 8 |

```
剣術適性(F) ─┬─(剣攻撃500・Lv10)──────────────→ 剣術の才(D) ─(剣3000・Lv30)→ 剣術の天才(B) ─(剣10000・Lv60・限界突破1)→ 剣聖の資質(S)
              └─(剣攻撃300・魔力親和性 or 魔法100)→ 魔剣適性(D) ─(剣2000・魔法500・Lv30)→ 魔力剣術(B) ─(剣8000・魔法3000・Lv60・限界突破1)→ 魔剣の極致(S)
剣の心得(後天F) ─(剣600・Lv10)→ 剣術の才(D) → …（剣術適性と同じ道）
弓術適性(F) / 弓の心得 → 弓術の才(D)　　槍術適性(F) / 槍の心得 → 槍術の才(D)
```
