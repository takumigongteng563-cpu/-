# 動作確認手順

第1弾（1〜8）と第2弾（9〜18）の確認手順です。第1弾から更新した場合は、先に「9. 更新」を行ってください。

実機（PC 統合版 → Realms → Switch）で、第1弾の完成判定項目を確認する手順です。
結果は [実装状況](実装状況.md) の表の「実機」列に記入してください。

## 準備

- PC でワールドを作成する際に **チートを ON** にしておくと、管理コマンドで状態を確認できます
- PC 版で **コンテンツログ** を有効にすると、エラーを確認できます
  - 設定 →「クリエイター」→「コンテンツログファイルを有効にする」「コンテンツログGUIを有効にする」を ON
  - ゲーム中にエラーが出ると画面にログが表示されます。`[魔神野口]` で始まる行がこのアドオンのログです
- 起動時にコンテンツログへ `[魔神野口][WARN][main] v0.1.0 起動 world=created index=created` のように出れば正常です
  - 2回目以降の起動では `world=loaded index=loaded` になります

## 1. ワールドを正常に起動できる

1. PC で新規ワールドを作成（BP を有効化）して入る
2. 確認：エラー表示が出ない／コンテンツログに起動メッセージが出る
3. `/scriptevent noguchi:status` → `[魔神野口] v0.1.0` から始まる状態表示が出る

## 2. 初回参加時にデータが生成される

1. 初めて入ったとき、チャットに「ようこそ、異世界へ。……種族：人間 / Lv1 / 無職」と表示される
2. 「冒険者の書を受け取った」と表示され、インベントリに冒険者の書（光っている本）がある
3. 冒険者の書を使う →「ステータス」→ 次を確認
   - 種族：人間／レベル：1／職業：無職／金貨：0 G
   - 基礎能力値：すべて 5／未使用能力ポイント：0
   - HP 100/100・MP 10/10・スタミナ 100/100

## 3. 再参加時にデータが維持される

1. 「設定」→「個人設定」→「保存したときに通知を表示する」を ON にして決定
2. ワールドから抜けて、もう一度入る
3. 確認：
   - チャットが「おかえりなさい、（名前）。冒険の記録を読み込みました。」になる（「ようこそ」ではない）
   - 冒険者の書が増えていない（1冊のまま）
   - 「設定」→「個人設定」のトグルが ON のまま
   - 「冒険者情報」の参加回数が 2 回になっている

## 4. 複数人のデータが混同されない

2～4人で同じワールド（Realm）に入って確認します。

1. 各自で「冒険者情報」を開き、**識別ID**がそれぞれ異なることを確認
2. 1人だけ「個人設定」の保存通知を ON にする → ほかの人の設定は OFF のまま
3. 1人が抜けて入り直す → その人の参加回数だけが増え、ほかの人の値は変わらない
4. 「冒険者情報」の「この世界の冒険者」に、オンラインのメンバーが正しく表示される

## 5. ワールド再起動後もデータが維持される

1. 3・4 の状態でワールドを閉じる（Realm の場合は全員が抜けて、Realm を「閉じる」→「開く」）
2. 再度入り、3 の確認項目がすべて維持されていることを確認
3. 「設定」→「データ状態の確認」で、状態が「正常」、復旧記録が 0 件であることを確認

## 6. RPG専用メニューが開く

1. 冒険者の書を手に持ち、**空に向けて**使う（Switch：ZL）→ メニューが開く
2. **ブロックに向けて**使う → メニューが開く（ブロックへの操作は行われない）
3. 11項目すべてを開き、「戻る」でメインメニューに戻れることを確認
4. 未実装の内容に「（今後実装予定）」と表示されることを確認
5. 冒険者の書をドロップしようとしても捨てられないことを確認
6. 死亡してリスポーンしても冒険者の書が残っていることを確認

開かない場合：`/scriptevent noguchi:menu` で開くか確認し、結果を記録してください（既知の問題2）。

## 7. 重大な Script API エラーが発生しない

1. 1～6 の操作中、コンテンツログに `[魔神野口][ERROR]` や赤いエラーが出ていないことを確認
2. 管理者タグを付けて（`/tag @s add noguchi_admin`）「設定」→「最近のエラー」を開き、「記録されたエラーはありません」と表示されることを確認

## 8. 行動制限（任意）

1. 管理者タグを付けた状態でサバイバルにする
2. 「設定」→「行動制限の設定」でブロック破壊を ON
3. 管理者タグを外す（`/tag @s remove noguchi_admin`）→ ブロックを壊せず「この世界ではブロックを壊せません」と表示される
4. クリエイティブモードでは壊せることを確認
5. 確認後は `/scriptevent noguchi:restrict break off` で戻す

# 第2弾の確認

テスト用に管理者タグを付けておくと便利です（`/tag @s add noguchi_admin`）。確認後は外してください。

## 9. 更新（第1弾から）・既存データの維持

1. 第1弾で遊んだワールドを**バックアップしてから** 0.2.0 に更新し、入る
2. 確認：チャットに「おかえりなさい」と「あなたに宿る才能：……」が出る
3. 「冒険者情報」の参加回数・初参加日時、第1弾で変えた個人設定が残っている
4. `/scriptevent noguchi:status` で `v0.2.0`、「設定 → データ状態の確認」で状態が「正常」

## 10. HUD

1. 画面下に `HP …  MP …  ST …` と `Lv 1  EXP 0/100  無職` の2行が出る（最大値は才能によって変わる）
2. ダッシュするとスタミナ（ST）が減り、止まると回復する
3. 「設定 → 個人設定」で HUD を OFF にすると消える

## 11. レベルアップ・複数レベル同時上昇

1. ゾンビを倒す → HUD の EXP が 10 増える（パーティ内で大きく遅れている人は追いつき補正で多め）
2. `/scriptevent noguchi:exp 2000` → 「LEVEL UP!」の表示・効果音、レベルが一気に5まで上がる
3. 「ステータス」で 未使用能力ポイントが 20（4レベル×5）、余った経験値が繰り越されている

## 12. 能力ポイント振り分け

1. 「ステータス → 能力ポイント振り分け」
2. 筋力を押す（+1）→「増やす量を変更」で 5 → 耐久を押す（+5）→「1つ戻す」で耐久の +5 が消える
3. 「確定する」→ 確認画面で「確定する」
4. 筋力が 1 上がり、未使用ポイントが 1 減る。確定した振り分けを戻す手段がないことを確認

## 13. 能力値の再計算

1. 「ステータス → 能力値の内訳」で、基礎・成長・振り分け・才能が別々に表示される
2. `/scriptevent noguchi:recalc` を何回実行しても数値が変わらない

## 14. 初期才能・再参加

1. 「才能」で 2〜3 個の才能と等級が表示される。ボタンで効果が見られる
2. 抜けて入り直す・死んでリスポーンする・ワールドを再起動する → 才能が同じ
3. 2人以上で、才能がそれぞれ違うことを確認（まれに一部が同じになることはある）

## 15. 後天性才能・才能進化

1. （後天性）剣を持ってゾンビ等に200回攻撃を当てる → 「剣の心得」が目覚める（剣術系の才能を持っていない場合）
   - 早く確かめる場合：ラヴェジャー・ウォーデンなどの強敵を倒すと「巨獣狩り」が目覚める
2. （進化）管理者メニュー「テスト機能 → 才能付与」で剣術適性 →「才能進化テスト」で「剣術適性 → 剣術の才」または「→ 魔剣適性」
3. 進化の演出（タイトル・効果音）が出て、「才能」の詳細に進化の軌跡が表示される

## 16. 潜在能力

1. 「才能」の潜在能力欄が「……何かが眠っている」となっていて、名前が出ていない
2. 「テスト機能 → 潜在能力覚醒テスト」→「潜在能力 覚醒」のタイトル・効果音・パーティクル・全体メッセージ
3. 「才能」に潜在能力の名前と効果が表示される

## 17. HP・MP・スタミナ

1. 敵から攻撃を受けると HUD の HP が減る（ハートの減り方と同じ割合）
2. `/scriptevent noguchi:vital mp 0` → 5秒ごとに MP が回復する
3. ダッシュし続けてスタミナを 0 にする → 足が遅くなる（鈍化）。止まって休むと回復して解除される
4. 死んでリスポーン → HP・MP・スタミナが満タン

## 18. マルチプレイ・再起動

1. 2〜4人で同時にメニューを開いて振り分けても、それぞれの値だけが変わる
2. 一般プレイヤー（タグなし）が `/scriptevent noguchi:exp 100` を実行しても拒否される
3. ワールド（Realm）を閉じて開き直し、レベル・振り分け・才能・覚醒した潜在能力が残っている
4. 遊んでいる間、コンテンツログに `[魔神野口][ERROR]` が出ない／管理者メニューの「最近のエラー」が空

# 最終仕様 Ver.1.0 対応（v0.2.1）の確認

## 19. 更新（v0.2.0 から）・データ移行

1. 第2弾で遊んだワールドを**バックアップしてから** 0.2.1 に更新して入る
2. 「ステータス → 能力値の内訳」に12種類（生命力・持久力・集中力・統率力を含む）が表示され、既存の8種の値が更新前と同じ
3. 第2弾で初期才能を2個以上持っていた人は「才能」の先天が1個になっている（[データ移行仕様](データ移行仕様.md)）
4. レベル・経験値・未使用ポイント・金貨が更新前と同じ
5. 新しく参加した人の初期才能が1個

## 20. 操作判定（Switch で最重要）

1. 管理者タグを付け、「設定 → テスト機能 → 操作判定テスト ON/OFF」（修練の触媒が配られる）
2. 修練の触媒を手に持ち、次の操作をして画面下の表示を記録する

| 操作 | 期待される表示 |
|---|---|
| 立ったまま ZL を短く押す | 通常使用（小技・小魔法） |
| ジャンプして空中で ZL | ジャンプ中に使用（中技・中魔法） |
| ダッシュしながら ZL | ダッシュ中に使用（移動技） |
| しゃがんで1秒ほど待ってから ZL | しゃがみながら溜めて使用（大技・大魔法） |
| しゃがんで2秒以上待ってから ZL | 長時間溜めて使用（奥義・超大魔法） |
| ZL を2秒以上押し続けて離す | 長時間溜めて使用（※発火しない可能性あり。結果を記録） |
| ZL を1秒ほど押して離す（しゃがまない） | 不発（溜め不足） |

3. 結果を [Switch検証状況](Switch検証状況.md) の表に記入する
4. 「操作判定テスト」を OFF にして ZL → 「技が割り当てられていない」と出る

## 21. ステージ・王国

1. 「ステージ情報」で「第1章」「富里王国：滅亡寸前」「施設：宿屋」と表示される
2. テスト機能 →「ステージクリア記録テスト」でステージ1 → 「ステージ情報」で王国が「復興中」、ステージ2が解放
3. もう一度ステージ1を記録 → 建物・住民が増えない（「ワールド進行データ確認」で確認）
4. ワールドを再起動しても記録が残っている

## 22. 潜在能力（形成方式）

1. 新しく参加したプレイヤーの「才能」に「まだ何も感じない」と表示される
2. 剣でモンスターを攻撃し続ける（約2,000回）→「何かが形になりつつある」に変わる（名前は表示されない）
3. テスト機能「潜在能力覚醒テスト」で覚醒 → 名前と効果が表示される
