# データ移行仕様（v0.2.1 最終仕様 Ver.1.0 対応）

**更新前に必ずワールドのバックアップを取ってください**（[バックアップ手順](バックアップ手順.md)）。移行は自動で行われ、元に戻す機能はありません。

## 移行のしくみ

- データはレコードごとに「データ構造のバージョン」を持ち、読み込み時に古い順から1段階ずつ変換します（`storage/migration.js`）。
- 変換後、現在の形に合わせて欠けた項目を補います（`storage/sanitize.js`）。**知らない項目は削除しません。**
- 移行に失敗したデータ、またはアドオンより新しいバージョンのデータは「保護モード（読み取り専用）」になり、上書きされません。
- 移行の記録はワールドの索引（`index.system.versionHistory`）に残ります。

| レコード | 旧 | 新 | 移行処理 |
|---|---:|---:|---|
| プレイヤー個人データ | v1（第1弾）/ v2（第2弾） | **v3** | `player/playerMigrations.js` |
| ワールド共有データ | v1 | **v2** | `world/worldMigrations.js` |
| 索引 | v1 | v1 | 変更なし |

第1弾（v1）のデータは v1 → v2 → v3 の順に変換されます。

## プレイヤー個人データ v2 → v3

| 項目 | 変換内容 | 旧データ |
|---|---|---|
| 能力値 `stats` | 既存8種（筋力・耐久・魔力・精神・敏捷・器用・幸運・知力）は**値をそのまま維持**。生命力 `lif`・持久力 `endr`・集中力 `foc`・統率力 `lead` を初期値 5 で追加 | 維持 |
| 成長・振り分け・未使用ポイント | 変更なし | 維持 |
| 初期才能 `talents.innate` | 2個以上あった場合、**最初の1個だけ**を残す | 元の一覧を `talents.innateLegacy` に保存 |
| 有効な才能 `talents.active` | 2個目以降の初期才能に由来するもの（進化後を含む）を無効化 | `talents.archived` に移して保存（削除しない） |
| 後天性・管理者付与の才能 | 変更なし | 維持 |
| 潜在能力 `hiddenPotential.entries` | 未覚醒の旧抽選結果に `legacy: true` を付けて無効化。**覚醒済みのものは有効のまま** | 記録として残る |
| 潜在能力の形成 | `hiddenPotential.formation` を追加（スコアは次回の判定時に計算） | - |
| 熟練度 `proficiency` | `{ weapon, magic, skill }` の形に変更。旧データの値は `weapon` に移す | 維持 |
| 追加項目 | 職業専用能力値 `specialStats`、技の割り当て `skillBindings`（9枠×5操作、すべて空）、ステージ記録 `stageRecords` | - |

第2弾で2個以上の初期才能を持っていた人の扱いは `balance/talentRoll.js` の `LEGACY_EXTRA_INNATE_POLICY` で切り替えられます（`"archive"`＝初期値／`"keep"`＝すべて残す）。**この設定は移行が行われる前（更新後の初回起動前）に変更してください。** 移行後に変更しても、すでに移行されたデータは戻りません（ただし `talents.archived` に記録が残っているため、管理者テストの才能付与で個別に戻すことはできます）。

## ワールド共有データ v1 → v2

| 項目 | 変換内容 | 旧データ |
|---|---|---|
| ストーリー `story.chapter` | 全20章 → 全10章。1～10 に収める | 旧値を `story.legacyChapter` に保存 |
| 唯一装備 `uniqueItems` | 旧形式 `owners` を新形式 `registry`（状態・所有者・通し番号・履歴）に写す | `owners` は残す |
| 追加：ステージ `stages` | ステージ1を解放済みにする。記録は空 | - |
| 追加：富里王国 `kingdom` | 滅亡寸前（住民：ホープのみ、施設：宿屋のみ） | - |
| 追加：クリア後 `postgame` | 未解放 | - |
| ダンジョン関連（`dungeons`・`dungeonResume`） | 変更なし（旧仕様・未使用） | 維持 |
| 潜在能力の割当記録（`talentStats`） | 変更なし（旧仕様・未使用） | 維持 |
