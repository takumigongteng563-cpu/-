# ファイル構成

```
minecraft/
├─ README.md                 概要・導入方法・更新手順・管理コマンド
├─ MASTER_SPEC.md            最終基本仕様書 Ver.1.0（仕様の正本）
├─ CHANGELOG.md              変更点一覧
├─ package.json              開発用ツール（型チェック・テスト・ビルド）の設定
├─ jsconfig.json             型チェック設定
├─ types/globals.d.ts        型チェック用のグローバル定義（console）
├─ dist/                     配布ファイル（npm run build で生成）
│   ├─ MajinNoguchi_v0.1.0.mcaddon
│   ├─ MajinNoguchi_BP_v0.1.0.mcpack
│   └─ MajinNoguchi_RP_v0.1.0.mcpack
├─ docs/                     各種ドキュメント
├─ devscripts/               開発用スクリプト（ゲームには含まれない）
│   ├─ validate-packs.mjs    パック構成の静的検証
│   ├─ build.mjs             .mcaddon / .mcpack の作成
│   ├─ make-textures.mjs     アイコン画像の生成
│   ├─ talent-table.mjs      才能一覧（docs/才能一覧.md）の生成
│   ├─ png.mjs / zip.mjs     PNG・ZIP の最小実装（外部依存なし）
├─ tests/                    テスト（ゲームには含まれない）
│   ├─ helpers.mjs           テスト用の保存先・疑似プレイヤー
│   ├─ storage.test.mjs      保存・破損検知・移行・修復の単体テスト
│   ├─ player.test.mjs       プレイヤー/ワールドデータの単体テスト
│   ├─ rpg.test.mjs          第2弾（レベル・能力値・才能・HP/MP/スタミナ・移行）の単体テスト
│   ├─ integration.test.mjs  統合テスト（main.js を模擬エンジンで起動）
│   ├─ integration/session.mjs     第1弾の統合シナリオ
│   ├─ integration/rpgSession.mjs  第2弾の統合シナリオ（第1弾データからの更新を含む）
│   ├─ integration/finalSession.mjs 最終仕様対応の統合シナリオ（第2弾データからの更新・操作判定・ステージ・王国）
│   ├─ final.test.mjs        最終仕様対応の単体テスト（移行・12能力値・484職業・100ステージ・王国・報酬・唯一装備・操作判定）
│   ├─ fixtures/v1-state.json      第1弾のコードで作ったセーブデータ（再生成禁止）
│   ├─ fixtures/v2-state.json      第2弾のコードで作ったセーブデータ（再生成禁止）
│   └─ mock/                 @minecraft/server・server-ui の模擬実装
└─ packs/
    ├─ BP/                   ビヘイビアーパック
    └─ RP/                   リソースパック
```

## ビヘイビアーパック（packs/BP）

```
BP/
├─ manifest.json             パック定義（script モジュール、@minecraft/server 2.0.0 / server-ui 2.0.0 依存）
├─ pack_icon.png
├─ texts/                    パック名の翻訳
├─ items/
│   ├─ adventurer_book.json  「冒険者の書」（noguchi:adventurer_book）
│   └─ skill_focus.json      「修練の触媒」（noguchi:skill_focus・操作判定の確認用）
└─ scripts/
    ├─ main.js               エントリーポイント。イベント購読と起動処理
    ├─ app.js                サービスの組み立て・参加時のRPG処理（第2弾）
    ├─ config.js             全体設定値（保存キー・バージョン・負荷調整値）
    │
    ├─ balance/              【設定ファイル】数値の調整はここ（第2弾）
    │   ├─ progression.js    必要経験値の式・能力ポイント・存在階級・余剰経験値・追いつき補正・暫定モンスター経験値
    │   ├─ stats.js          初期能力値・初期HP/MP/スタミナ・派生能力値の式・上限
    │   ├─ growth.js         基本成長率・成長率補正の上下限
    │   ├─ talentRoll.js     等級の確率・初期才能の数
    │   ├─ vitals.js         回復・スタミナ
    │   ├─ hud.js            HUD の更新間隔
    │   ├─ input.js          操作判定の時間（最終仕様）
    │   └─ rewards.js        報酬の確率・周回補正の上限（最終仕様）
    │
    ├─ progression/          レベル（第2弾）
    │   ├─ levelMath.js      必要経験値・経験値加算（繰り越し・上限）
    │   └─ progressionService.js 経験値付与の共通処理・レベルアップ・限界突破
    ├─ stats/                能力値（第2弾）
    │   ├─ statCalc.js       層ごとの能力値・派生能力値の計算
    │   ├─ statService.js    再計算・一時効果
    │   ├─ growth.js         成長率による自動成長
    │   └─ allocation.js     自由振り分け（下書き・確定・再振り分け）
    ├─ talents/              才能（第2弾）
    │   ├─ conditions.js     覚醒・進化条件の判定
    │   ├─ talentRoller.js   初期才能の抽選
    │   ├─ potentialFormation.js 潜在能力の形成（最終仕様）
    │   └─ talentService.js  抽選・獲得・進化・覚醒
    ├─ actions/              行動の記録（第2弾）
    │   ├─ actionService.js  行動回数・フラグ
    │   └─ combatHooks.js    命中・討伐・被ダメージの記録、暫定の討伐経験値
    ├─ vitals/               HP・MP・スタミナ（第2弾）
    │   ├─ vitalsService.js  消費・回復・疲労
    │   └─ vitalsRuntime.js  バニラ体力との連動・自然回復・スタミナ・移動距離
    ├─ hud/hud.js            アクションバーHUD（第2弾）
    ├─ fx/effects.js         演出（第2弾）
    │
    ├─ input/                ホットバー複数操作（最終仕様）
    │   ├─ inputResolver.js  操作の判定（純粋な計算）
    │   ├─ skillBindingService.js 技の割り当て・発動チェック・クールタイム
    │   └─ inputRuntime.js   ゲーム内の操作判定・操作判定テスト
    ├─ stages/stageService.js     100固定ステージの解放・記録・章の進行（最終仕様・基盤）
    ├─ kingdom/kingdomService.js  富里王国の復興データ（最終仕様・基盤）
    ├─ rewards/              個別報酬の抽選（最終仕様・基盤）
    ├─ unique/uniqueItemService.js 世界唯一の装備の管理（最終仕様・基盤）
    │
    ├─ core/                 共通基盤
    │   ├─ log.js            ログ出力（コンテンツログ）・直近エラーの記録
    │   ├─ safe.js           エラー隔離（try/catch ラッパー）
    │   ├─ events.js         イベント購読ヘルパー（エラー隔離・API未提供時のスキップ）
    │   ├─ scheduler.js      定期処理（毎tick処理を使わない）
    │   ├─ context.js        サービスの共有（ctx）
    │   ├─ ids.js            プレイヤー識別IDの生成
    │   ├─ hash.js           チェックサム（破損検知）
    │   ├─ ascii.js          保存前のASCII化（文字化け・分割破損防止）
    │   ├─ rng.js            シード付き乱数（第2弾）
    │   ├─ eventBus.js       内部イベント（第2弾）
    │   └─ players.js        プレイヤー検索（第2弾）
    │
    ├─ storage/              セーブシステム
    │   ├─ chunkedStore.js   分割保存・A/B二重化・破損検知・復旧・退避
    │   ├─ recordManager.js  キャッシュ・変更検知・保存・移行・修復の共通処理
    │   ├─ migration.js      データ構造バージョンの移行
    │   ├─ sanitize.js       欠損補完・型修復（未知の項目は削除しない）
    │   ├─ saveManager.js    自動保存・全保存・保存通知
    │   └─ worldBackend.js   保存先＝ワールドの動的プロパティ
    │
    ├─ player/               プレイヤー個人データ
    │   ├─ playerSchema.js   個人データの構造（初期値）
    │   ├─ playerMigrations.js 個人データの移行処理
    │   ├─ playerService.js  識別・参加・退出・更新・保存
    │   └─ indexSchema.js    プレイヤー索引・バージョン履歴・復旧記録
    │
    ├─ world/                ワールド共有データ
    │   ├─ worldSchema.js    共有データの構造（初期値）
    │   ├─ worldMigrations.js
    │   └─ worldService.js   読み込み・更新・保存
    │
    ├─ party/partyService.js マルチプレイ基盤（人数・人数別倍率表・NPC補完の差し込み口）
    ├─ rules/actionGuard.js  行動制限（破壊・設置・使用）
    ├─ items/adventurerBook.js 冒険者の書の配布・判定
    ├─ admin/scriptEvents.js 管理コマンド（/scriptevent noguchi:*）
    ├─ admin/adminAuth.js    管理者判定（第2弾）
    │
    ├─ content/              ゲーム内容の定義（今後ここに大量追加する）
    │   ├─ registry.js       定義の登録（ID重複を拒否）
    │   ├─ index.js          定義の一覧
    │   ├─ races.js          種族（人間）
    │   ├─ jobs.js           職業（無職）
    │   ├─ ranks.js          冒険者ランク（未登録）
    │   ├─ stats.js          能力値・派生能力値の表示定義
    │   ├─ equipmentSlots.js 装備スロット
    │   ├─ grades.js         才能の等級（第2弾）
    │   ├─ tiers.js          存在階級の参照（第2弾）
    │   ├─ potentials.js     隠された潜在能力10種（最終仕様で形成方式に変更）
    │   ├─ specialStats.js   職業系統の専用能力値（最終仕様・基盤）
    │   ├─ jobTree.js        484職業のツリー（最終仕様・基盤）
    │   ├─ story.js          全10章（最終仕様・基盤）
    │   ├─ stages.js         100固定ステージ（最終仕様・基盤）
    │   ├─ kingdom.js        富里王国の住民・建物・施設（最終仕様・基盤）
    │   ├─ npcs.js           NPC（ホープ）（最終仕様・基盤）
    │   ├─ rewardTables.js   報酬表（最終仕様・基盤）
    │   ├─ uniqueItems.js    世界唯一の装備（最終仕様・基盤）
    │   ├─ skills.js         スキル定義の器（最終仕様・基盤）
    │   └─ talents/          才能（第2弾）：schema.js（書き方）/ innate.js（初期40）/ evolved.js（進化8）/ acquired.js（後天14）/ index.js
    │
    └─ ui/                   RPG専用メニュー
        ├─ menu.js           メインメニュー（11項目）
        ├─ formUtil.js       フォーム表示（UserBusy 再試行・多重表示防止）
        ├─ format.js         表示整形
        ├─ describe.js       才能の効果の文章化（第2弾）
        └─ pages/            各ページ（status / job / skill / talent / equipment /
                              title / quest / adventurer / dungeon / storage / settings）
                              ＋ allocation（能力ポイント振り分け）/ adminTest（管理者テスト）（第2弾）
```

`storage/`・`player/`・`world/`・`party/`・`content/`・`balance/`・`progression/`・`stats/`・`talents/`・`actions/actionService.js`・`vitals/vitalsService.js`・`app.js` と `core/` の一部は `@minecraft/server` に依存しない純粋なロジックで、
Node.js 上で単体テストできるようにしています。ゲームの API に触れるのは `main.js`・`worldBackend.js`・`scheduler.js`・`core/players.js`・`ui/`・`rules/`・`items/`・`admin/scriptEvents.js`・`actions/combatHooks.js`・`vitals/vitalsRuntime.js`・`hud/`・`fx/` です。

## リソースパック（packs/RP）

```
RP/
├─ manifest.json
├─ pack_icon.png
├─ texts/
│   ├─ languages.json
│   ├─ ja_JP.lang            アイテム名「冒険者の書」
│   └─ en_US.lang            英語設定でも日本語名を表示
└─ textures/
    ├─ item_texture.json     アイコン定義
    └─ items/adventurer_book.png, skill_focus.png
```
