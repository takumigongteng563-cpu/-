作り方
Claude Code で作る
ネット越しのオンライン対戦
プレイヤーは最大4人・最低2人。足りない枠はAIが動かす
陣地は30個

世界観
魔王ヤギュー：山羊の魔王。剣で戦い、手下も使う。拠点は岩の城（魔王城）
勇者スミレ・賢者野口・魔法使い七星：絶対女王のぞちちの命で魔王討伐の任務を受けた三人
絶対女王のぞちち：王国の女王
王国 vs 魔族の戦い
テーマ
戦争がテーマ。遊びながら戦争について学べる、社会学習的なゲームにする。ゲームの仕組みで次の
ことを体験できるようにする：
1.  戦争にはお金と食料がいる：兵を動かすと食料が減る。補給が切れると兵が弱る、逃げる
2.  戦争は民の暮らしを壊す：合戦があった陣地は畑が荒れて民が減る。勝っても復興に時間がかか
る
3.  なぜ戦争が起きるか：資源の取り合い、恐怖や不満、指導者の考え。魔族にも魔族の事情がある
シナリオ（ストーリー）も作る。
登場人物と性格（シナリオの土台）
魔族側
魔王ヤギュー：もとは山で暮らしていた人間。豊かな暮らしをしている人間が許せず、悪魔と契
約して山羊の魔王になった
CAR：山に住んでいて、ヤギューに助けられて手下になった。ひとりだと弱いが群れると強い。
ヤギューの目線でしか物事が見えていない
OH：辺境の町に住んでいた人間。王国の支援が届かず家族を亡くし、のぞちちを恨んでいる。
ヤギューの方がいいと思って魔族についた
KKB：度胸はないが傲慢。ヤギューの強さに酔って全能感に浸っている。作戦を立てるのがうま
く、ヤギューの「前足」として重宝され、忠誠心も強い
王国側
絶対女王のぞちち：人を治める者。近しい人には優しく楽しく接するが、遠くの人や関わりのな
い人には無関心
勇者スミレ：のぞちちの近くにいて、たくさん恩を受けてきた。恩を返したい。いい人ののぞち
ちを攻めるヤギューが嫌いで、倒すべきだと思っている
賢者野口：のぞちちからいろいろなことを教わった。ひとりで研究に打ち込み、のぞちちから任
された仕事をこなすことに喜びを感じている
魔法使い七星：最初はヤギューに無関心だったが、友達のゆきちゃんが敵視し始めたので一緒に
敵対するようになった
ゆきちゃん：静かに暮らしていたのに、ヤギューが戦争を始めたので敵視している。ゲームで
は：
ストーリーイベントで七星と関わる
ゆきちゃんの町が無事かどうかで、七星のやる気（ステータス）が変わる
戦争が進むと、イベントしだいで兵士として戦場に出てくる

なった

ゲームの形
昔の信長の野望のような国取りゲーム
全部ターン制
1ラウンド＝1日
ふだんの1日：全員が同時に「今日やること」（内政・移動など）を決めて、準備完了ボタンを押
す。全員そろったら、その日の結果がまとめて一斉に反映される
合戦だけは別枠：戦場画面に切り替わり、全部隊が速さ順に1部隊ずつ動くターン制
制限時間はつけない（ふだんの1日も合戦も、みんなでのんびり考える）
季節はとりあえずなし（あとで足すかも）
プレイヤーの役割
ヤギュー側：1人
勇者側：3人（スミレ・野口・七星）
のぞちち：AI
勝利条件
勇者の勝ち：ヤギューを倒す ＋ 陣地の大半を取る
ヤギューの勝ち：次のどちらか
勇者三人を全員倒す ＋ 陣地の大半を取る
女王のぞちちを倒す（即勝ち）

ヤギューは魔王城から復活する
復活地点を取られたら復活できない
取り返せばまた復活できる（ヤギュー側は手下が取り返してもOK）

AIが自動で動かす。状況を見て最適な行動をとる

る

魔法を撃ち込む

マップの一番奥にあって、攻め込むのに時間がかかる
勇者
操作できるのは自分のキャラ本人だけ
王国の領地は三人で共有。仲間の領地へ助けに行ける
勇者は武将を登用して家臣にできる。家臣には、その勇者が毎日命令を出す（陣地で内政、移
動、出陣）。家臣が増えるほど一度にできることが増える（下の「武将の登用と処断」）

内政（魔族側・ヤギュー）
王国とはやり方が違う、魔族らしい内政。
民は恐怖で治める。恐怖が高いと逆らわないが、下がりすぎると反乱
恐怖から魔力が生まれる
魔力で手下を生み出す、闇の儀式（陣地の強化、勇者を呪う、など）
食料：魔族の民と兵も食べる。足りなくなると、王国と同じく兵が弱ったり逃げたりする
開墾：畑を増やして食料を増やす
放牧：山羊を育てて食料を増やす。岩山でもできる、魔族のための畑
民を増やす
分け与え：民に食料を配って暮らしを良くする。民が増えやすく、反乱も起きにくくなる。ただ
し恐怖が少し下がるので、生まれる魔力も減る（民を怖がらせて力を得るか、民の暮らしを豊か
にするか、で悩む）

レベルが上がるほど、必要な魔力が大きく増える
